Repositório criado para armazenar exercícios práticos de introdução à linguagem Python.


- Atividade acadêmica desenvolvida durante a aula, focado em conhecimentos em lógica de programação e fundamentos da linguagem Python, trabalhando com variáveis, tipos de dados, operadores matemáticos e lógicos, entrada e saída de dados, estruturas condicionais e estruturas de repetição. Também pratiquei a resolução de problemas por meio de exercícios de programação.
